# BOARD.md — Arduboy ハードウェア仕様

## ハードウェア仕様

| 項目 | 仕様 |
|------|------|
| ディスプレイ | 128×64 ピクセル 単色OLED |
| CPU | ATmega32U4 |
| RAM | 2.5 KB |
| Flash | 32 KB |
| ボタン | Up / Down / Left / Right / A / B |

### ボタン配置

```
+------------------------------------------+
| +--------------------------------------+ |
| |      128×64 OLED ディスプレイ          | |
| |                                      | |
| +--------------------------------------+ |
|  [UP]                                    |
|[LEFT][RIGHT]                  [B]        |
|  [DOWN]                    [A]           |
+------------------------------------------+
```

- ディスプレイ: 128×64 ピクセル 単色OLED（上部）
- 左側: 十字キー（UP / DOWN / LEFT / RIGHT）
- 右側: A ボタン（左下）・B ボタン（右上）の斜め配置
